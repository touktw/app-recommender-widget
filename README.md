# 앱 추천 위젯

이 시간대에 자주 쓰던 앱을 홈 화면 위젯으로 추천해 줘요.

## 동작 방식
- 앱이 따로 기록을 쌓지 않고, Android가 이미 남기는 앱 사용 기록(UsageStats)의 최근 28일치를 읽어요.
- 앱마다 요일 × 0~23시 1시간 단위 사용 횟수를 세요. 최근 기록일수록(7일마다 절반) 1회를 크게 세요. 4주 기록은 요일별 표본이 적어서 같은 요일 기록(60%)과 모든 요일 평균(40%)을 섞어 써요.
- 점수 = 지금 시간대 사용 횟수 × 시간대 집중도. 집중도는 그 앱 사용량 중 지금 시간대 비율 × 24라서, 하루 종일 고르게 쓰는 앱(유튜브, 브라우저)은 약 1, 특정 시간에만 쓰는 앱(식권 앱)은 24에 가까워요.
- 반복 보너스: 같은 요일·시간에 여러 주에 걸쳐 쓴 앱은 반복한 주 하나당 0.5배씩 더해요(4주 연속이면 2.5배).
- 위젯은 2x1(앱 3개)과 2x2(앱 7개) 두 크기이고, 마지막 칸은 항상 더보기예요. 더보기를 누르면 시간대별 순위 화면이 열려요. 위쪽 요일·시간 칩으로 고르면 그 요일·시간대의 순위(최대 20개)와 반복한 주 수, 비중, 점수를 볼 수 있어요.
- 매 정각 직후(WorkManager 1시간 주기), 그리고 앱 화면을 열 때 다시 계산해요.
- 런처, 시스템 UI, 이 앱 자신은 제외해요.
- 순위 화면에서 "고정"을 누른 앱은 점수와 상관없이 위젯 앞칸에 고정한 순서대로 나오고, 남은 칸을 추천으로 채워요.

## 실행
1. Android Studio에서 이 폴더를 열고 기기에 설치해요.
2. 앱을 열어 "사용 기록 접근 설정 열기"에서 이 앱을 허용해요.
3. 홈 화면 위젯 목록에서 "지금 쓸 앱"을 추가해요. 기본 2x1이고 세로로 늘리면 2x2가 돼요.

## 조정 포인트
`Recommender.kt` 맨 위 상수(LOOKBACK_DAYS, HALF_LIFE_DAYS, REPEAT_BONUS_PER_WEEK)와 `UsageGrid.SAME_DAY_WEIGHT`로 추천 성향을 바꿀 수 있어요.

## 구조
- `Recommender.kt` 사용 기록 읽기와 시간대 점수 계산
- `widget/RecommendWidget.kt` Glance 위젯 UI (2x1/2x2, 마지막 칸 더보기)
- `widget/RecommendWidgetReceiver.kt` 위젯 등록, 갱신 작업 시작/중지
- `widget/RefreshWorker.kt` 30분 주기 갱신
- `MainActivity.kt` 더보기 화면(시간대별 순위)과 권한 안내
